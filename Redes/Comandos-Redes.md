# Comandos de Rede — QEVIT

Abra o CMD ou PowerShell. Alguns comandos podem requerer permissões elevadas.

| Comando | Descrição |
|---|---|
| `ipconfig` | Mostra configuração IP básica |
| `ipconfig /all` | Mostra detalhes dos adaptadores |
| `ping 1.1.1.1` | Testa conectividade IP |
| `nslookup example.com` | Consulta DNS |
| `tracert example.com` | Mostra o caminho até ao destino |
| `arp -a` | Lista entradas ARP |
| `route print` | Mostra tabela de rotas |
| `netstat -ano` | Lista conexões e portas locais |
| `hostname` | Mostra nome do computador |

## Nota
Regista os resultados antes de alterar a configuração. Evita executar comandos de reset sem compreender o impacto.
